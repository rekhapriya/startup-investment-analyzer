# 💼 Startup Investment Analyzer

An interactive Streamlit application that helps an investment company store, explore, and analyze startup data before making investment decisions.

**Assignment 6 | AI & ML Course | Wenchwise (Evening Batch)**

## Features
- Store startup information (name, sector, investment amount, founded year, location)
- Display all available startups in a sortable table
- Search startups by name or sector
- Identify the startup with the highest investment
- Identify the startup with the lowest investment
- Calculate total investment across all startups
- Calculate average investment
- Analyze startups grouped by business sector (count, total, average) with charts

## Tech Stack
- Python 3
- Streamlit
- Pandas

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
